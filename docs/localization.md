# Localization

Bulgarian is the primary language. English is secondary.

## Locale Defaults

- Default locale: `bg`
- Secondary locale: `en`
- Default market: Bulgaria
- Default timezone: `Europe/Sofia`

## Web Routing

Use locale-aware routes:

```txt
/bg/...
/en/...
```

SEO-critical routes must include localized metadata, canonical URLs, and `hreflang` links.

## Copy Quality

Bulgarian copy must sound natural to Bulgarian sports fans. Do not accept literal machine translation for visible product text, SEO titles, or sports terminology.

## Localizable Data

These may need localized display values:

- Countries
- Leagues
- Teams
- Venues
- Match statuses
- Event names
- Odds markets
- Statistics labels

## Future Markets

Build localization so another country can be added without changing the core data model or client architecture.
